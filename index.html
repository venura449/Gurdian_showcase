The Problem
01 — Research Context

Social media has become
a vector for human-layer attacks.

Conventional defenses — reactive platform moderation, traditional antivirus tools — fail to address the linguistic nuances of modern threats. The Guardian fills this gap with proactive, explainable, non-intrusive AI.

🔥
Hate Speech
Detection of explicit and implicit toxicity including coded "dog whistles," slang variants, and context-dependent language using fine-tuned Transformer models.
Primary Focus
📰

Coordinated false narratives that erode societal trust. Real-time classification of unverified claims and deceptive framing before user engagement.
High Priority

Sophisticated social engineering exploiting trust, urgency, and cognitive biases. NLP-based identification of fraudulent language patterns.

03 — Project Journey

How The Guardian
was built.

Phase 01
Literature Survey & Research Gap
Surveyed 20+ papers on hate speech detection, NLP pipelines, and human-centric social media threats. Identified critical gap: existing models excel at explicit hate but fail on implicit, context-dependent toxicity including coded slang and "dog whistles."
Davidson et al. 2017 HateXplain 2021 ToxiGen 2022 20+ Papers Reviewed
Phase 02
Data Acquisition & Preprocessing
Primary datasets include the Davidson Twitter corpus for hate vs. offensive classification, and HateXplain for explainable toxic-span annotations. Custom-labeled samples created for nuanced edge cases including coded language and multilingual slang. Preprocessing via spaCy and NLTK.
spaCy NLTK Data Augmentation Back-Translation Hugging Face
Phase 03
Model Training & Fine-Tuning
Fine-tuned BERT and DistilBERT models on multiclass classification (Hate / Offensive / Neutral). Incorporated attention mechanisms for toxic span highlighting, multi-task learning for rationale generation, and adversarial training for bias mitigation across demographic subgroups.
BERT DistilBERT Transfer Learning Bias Mitigation Demographic Parity
Phase 04
Backend & API Development
Python FastAPI backend hosting four independent NLP modules. Each module processes text concurrently and returns structured JSON with label, confidence score, triggered keywords, and a brief rationale. Supports 100 concurrent analyses with sub-2-second response times.
FastAPI Python JSON API Cloud GPU (AWS/Colab)
Phase 05
Browser Extension & UI
Lightweight JavaScript/HTML/CSS extension that scrapes visible text on scroll, packages it into HTTPS requests, and renders color-coded overlay icons with explainable tooltips. Red for high-risk hate speech, orange for subtle toxicity. Non-intrusive by design — informs without blocking.
JavaScript HTML/CSS Chrome / Firefox / Edge HTTPS
Phase 06
Evaluation & Fairness Analysis
Targeting >90% accuracy on explicit hate, >80% recall on implicit toxicity, <5% false positives on legitimate critiques. Fairness evaluation using demographic parity and equal opportunity metrics across gender and race subgroups, targeting <10% disparity.
Precision / Recall ROC Curves Fairness Metrics Postman Jupyter Notebooks

07 — User Experience

Seven steps from
scroll to insight.

📱
01
User Browses
Extension reads visible post text as user scrolls. Only the text needed — no long-term local storage without opt-in.
📡
02
Request Sent
JSON payload (text + platform + post ID) sent over HTTPS to FastAPI gateway. Anonymized for privacy.
🧠
03
NLP Analysis
Fine-tuned Transformer processes text: classification label + confidence score + toxic span detection.
🔑
04
Keyword Match
Keyword matcher scans for hateful tokens, coded phrases, slang variants. Builds ranked trigger list.
📦
05
JSON Response
Formatter packages label, confidence, triggered_keywords[], and explanation into a single response object.
🎨
06
Icon Overlay
Extension maps result to color-coded icon. Red = high-risk, orange = subtle, green = clear. Appears next to content.
💡
07
User Informed
Hover opens tooltip explaining why content was flagged and listing triggered keywords. Never censors. Always educates.
🔁
∞
Continuous Learning
Optional feedback loop. User reports refine thresholds. Models retrained on evolving slang and emerging contexts.
08 — Project Details

The research behind
The Guardian.

"The Guardian" is an undergraduate dissertation project in the B.Sc. (Hons) Information Technology (Cyber Security) program at the Sri Lanka Institute of Information Technology. It addresses the critical gap between reactive platform moderation and proactive, user-centric cybersecurity.

The system's key contribution lies in its hate speech module — going beyond keyword matching to detect subtle, context-dependent toxicity including dog whistles, coded slang, and implicit bias, while ensuring fairness across demographic subgroups.
