01 — The Battlefield

Social media has become
a vector for human-layer attacks.

Conventional defences — reactive moderation, legacy antivirus — cannot decode the linguistic nuances of modern threats. The Guardian fills that gap with proactive, explainable, non-intrusive AI.

🔥
Hate Speech
Detection of explicit and implicit toxicity — coded "dog whistles," slang variants, and context-dependent language — via fine-tuned Transformers with rationale-based explanations.
Primary Module
Module Overview
Fine-tuned BERT / DistilBERT on the HateXplain & Davidson corpus. Classifies posts into Hate / Offensive / Neutral with attention-based toxic span highlighting. Targets >90% explicit accuracy and >80% implicit recall.

03 — Project Journey

How The Guardian
was forged.

Phase 01
Literature Survey & Research Gap
Surveyed 20+ papers on hate speech detection, NLP pipelines, and human-centric social media threats. Critical gap identified: models excel at explicit hate but fail on implicit, context-dependent toxicity including coded slang and dog whistles.
Davidson et al. 2017HateXplain 2021ToxiGen 202220+ Papers
Phase 02
Data Acquisition & Preprocessing
Primary datasets: Davidson Twitter corpus and HateXplain for explainable toxic-span annotations. Custom-labeled samples for nuanced edge cases. Preprocessing via spaCy and NLTK with back-translation augmentation.
spaCyNLTKBack-TranslationHugging Face
Phase 03
Model Training & Fine-Tuning
Fine-tuned BERT and DistilBERT on multiclass classification (Hate / Offensive / Neutral). Attention mechanisms highlight toxic spans; adversarial training mitigates demographic bias.
BERTDistilBERTTransfer LearningDemographic Parity
Phase 04
Backend & API Development
Python FastAPI backend hosting four independent NLP modules. Each returns structured JSON with label, confidence, triggered keywords, and rationale. Supports 100 concurrent analyses with <2s response times.
FastAPIPythonJSON APICloud GPU
Phase 05
Browser Extension & UI
Lightweight JavaScript extension that scrapes visible text, sends HTTPS requests, and renders color-coded icons with explainable tooltips. Non-intrusive by design — informs without blocking.
JavaScriptHTML / CSSChrome / Firefox / Edge
Phase 06
Evaluation & Fairness Analysis
Targets: >90% explicit hate accuracy, >80% implicit recall, <5% false positives on legitimate critiques. Fairness evaluation using demographic parity across gender and race, targeting <10% disparity.

Undergraduate Thesis Report:
The Guardian — AI-Powered Human-Layer Threat Detection
SLIIT · 2025–2026 25-26J-041 B.Sc. (Hons) IT — Cybersecurity Fernando M R I
Abstract
This dissertation presents The Guardian, a modular AI-powered browser extension designed to detect human-layer cybersecurity threats on social media platforms in real time. The system addresses four critical threat categories: hate speech, misinformation, phishing/scams, and PII exposure. The primary contribution is a fine-tuned BERT/DistilBERT pipeline capable of detecting both explicit and implicit hate speech — including coded dog whistles and contextual toxicity — with >90% accuracy and demographic fairness guarantees.
Key Contributions
• Modular four-component NLP detection architecture
• Implicit hate speech detection via attention-based toxic span highlighting
• Fairness evaluation framework with demographic parity analysis
• Non-intrusive browser extension that informs without censoring
• FastAPI backend supporting 100+ concurrent analyses at <2s latency

NLP-Based Human-Layer Threat Detection for Social Media
NLP Cybersecurity Hate Speech Detection BERT
Research Focus
This paper examines the gap between conventional cybersecurity tools and the linguistic complexity of modern social-media threats. It proposes a modular NLP detection pipeline combining transformer-based models with interpretable keyword triggering and demographic fairness constraints. The central challenge addressed is the detection of implicit hate speech — language that is contextually toxic but not explicitly flagged by keyword filters.
Methodology Summary
• Fine-tuning BERT / DistilBERT on HateXplain + Davidson corpus
• Back-translation augmentation for underrepresented categories
• Adversarial training for demographic bias mitigation
• spaCy NER for PII detection with custom entity types
• Concurrent module execution via async FastAPI endpoints
Target Metrics
>90% accuracy on explicit hate · >80% recall on implicit toxicity
<5% false positives · <10% demographic bias disparity · <2s API latency
