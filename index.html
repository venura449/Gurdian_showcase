About The Project

Built for a Safer Digital World

The Guardian is a modular AI-powered cybersecurity system designed to protect users from human-layer threats on social media. It combines multiple intelligent detection modules into a single browser extension.

The system extracts visible text from web pages and routes it to a FastAPI backend, where specialized AI models evaluate content and return structured risk insights. Unlike traditional security tools, The Guardian focuses on user awareness and education.

Academic Research

Research Domain

Foundational analysis, objectives, methodology, and system design of The Guardian research.

Research Domain
Literature Survey
Recent research highlights a growing shift in cybersecurity toward addressing human-layer risks on social media, where users are exposed to misinformation, hate speech, scams, and privacy threats. While advanced NLP models such as transformer-based systems have improved detection of harmful content, most existing solutions are reactive, single-purpose, and lack contextual understanding.
Research Domain
Research Gap
Existing AI solutions for misinformation, hate speech, scams, and PII exposure are fragmented and mostly single-purpose. They struggle with combined, context-dependent social media risks and often miss OpSec signals such as routine disclosure and future travel vulnerability. Real-time explainability and actionable user guidance are also commonly missing.
Research Domain
Research Problem
How can a proactive, real-time, and user-centric system be designed to accurately detect and integrate multiple forms of harmful content, including misinformation, hate speech, scams, and contextual privacy/OpSec risks, while providing explainable feedback and safe alternatives before content is shared?
Research Domain
Research Objectives
  • Design a unified detection system across four threat types.
  • Use hybrid rule-based + ML detection strategies.
  • Infer contextual privacy/OpSec risks beyond explicit PII.
  • Generate explainable feedback for better user understanding.
  • Provide safe rewrite suggestions while preserving user intent.
  • Implement as a real-time browser extension solution.
  • Evaluate accuracy, usability, and real-time feasibility.
Research Domain
Methodology
  • Design modular architecture with integrated detection modules.
  • Prepare PANORAMA data and custom OpSec scenarios.
  • Implement PII detection using Regex + NER.
  • Build OpSec detection with rules + contextual inference.
  • Train ML models for misinformation, hate speech, and scams.
  • Apply unified risk scoring across module outputs.
  • Generate explanations and safe rewrite suggestions.
  • Integrate frontend extension with backend REST API.
  • Evaluate using precision, recall, accuracy, and usability.
Research Domain
Architecture Design
System architecture has been completed as a modular, real-time pipeline connecting browser extension input, FastAPI services, multi-model NLP analysis, risk scoring, and user guidance output.
Research Domain
Technologies Used
  • Programming Language: Python
  • Backend Framework: FastAPI
  • Frontend: HTML, CSS, JavaScript (Browser Extension)
  • Machine Learning: PyTorch / Hugging Face Transformers
  • NLP Libraries: spaCy, NLTK
  • Models: BERT, DistilBERT, RoBERTa
  • Data Processing: Pandas, NumPy
  • API Communication: REST APIs (JSON)
  • Version Control: Git and GitHub
  • Development Tools: VS Code
  • Deployment/Testing: Uvicorn (Local Server)

Workflow

How It Works

Six steps from browsing to protection — all happening invisibly in under a second.

01

Browse

User browses social media normally. The extension runs silently in the background without disruption.

02

Extract

Visible page text is extracted and preprocessed by the content script for analysis.

03

Transmit

Data is securely sent to the FastAPI backend over encrypted channels in milliseconds.

04

Analyze

All four AI modules run in parallel, simultaneously evaluating for different threat types.

05

Classify

Threats are risk-scored, classified by severity, and structured into a JSON response object.

06

Alert

Non-intrusive tooltip alerts inform the user with clear, human-readable explanations and context.

THESIS · 2025

AI-Powered Cybersecurity Shield: Multi-Module Real-Time Threat Detection for Social Media

Sri Lanka Institute of Information Technology

© 2025 — All Rights Reserved
Title
AI-Powered Real-Time Cybersecurity Threat Detection on Social Media
Authors
Vishwa J. R. · De Alwis H.P.G.H.S. · Fernando M. R. I. · Herath H.M.G.D.K.
Abstract
This thesis presents The Guardian — a browser extension integrating four AI modules (scam/phishing detection, misinformation classification, hate speech detection, and PII/OpSec protection) into a unified real-time cybersecurity system. Using transformer-based NLP models deployed via a FastAPI backend, the system achieves high accuracy detection with zero user data storage. The work contributes novel hybrid detection approaches and adaptive user education features.
