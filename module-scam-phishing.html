Module 01

Scam & Phishing Detection

Real-time detection of scam and phishing threats by combining URL structure analysis with contextual understanding of surrounding text.

DistilBERT URL Analysis PhishTank Hybrid Fusion

Description

This module provides real-time detection of scam and phishing threats in user-facing web content by combining structural URL analysis with contextual understanding of text. By analyzing both the structure of links and the intent conveyed through surrounding content, the system detects explicit phishing attempts and subtle socially engineered scams.

  • Combines URL analysis with contextual text understanding
  • Detects explicit phishing and subtle scam language
  • Provides real-time, non-intrusive risk feedback

Problem Context

Social media and web platforms have become primary channels for the spread of phishing and scam-related content. Attackers increasingly combine malicious URLs with persuasive messaging to deceive users into revealing sensitive information or engaging with harmful content.

  • Modern scams use urgency, impersonation, and misleading narratives
  • Traditional detection often looks at only URL or text signals
  • Real-time protection is needed during ordinary browsing

Our Approach

Path A: Heuristic URL Analysis

Rule-based analysis identifies suspicious URL characteristics such as obfuscation, shortening services, and abnormal domain structures.

  • Suspicious keywords like login and verify
  • IP-based URLs
  • Excessive length and obfuscation

Path B: Contextual Scam Detection

A fine-tuned DistilBERT model analyzes surrounding text to detect urgency, impersonation attempts, and social engineering language patterns.

  • Urgency and pressure tactics
  • Financial incentives or rewards
  • Context-driven scam intent

System Architecture

The browser extension extracts URLs and surrounding text, sends them to the backend API, and combines heuristic URL analysis with AI-based text classification through a fusion engine to produce a final risk score.
