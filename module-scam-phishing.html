Module 01

Scam & Phishing Detection

Dual-path detection engine for suspicious links and deceptive text. This module combines URL heuristics, blacklist checks, and DistilBERT-based language understanding to surface fraud signals before the user clicks.

DistilBERT URL Analysis PhishTank Hybrid Fusion

Description

This module inspects links, sender intent, and urgent phrasing to identify scam attempts, impersonation patterns, and phishing language. It is designed to work as a fast, explainable safety layer for social media content.

  • Detects urgency, reward bait, and account-lock threats
  • Combines text signals with URL and domain checks
  • Shows a safe preview before any risky action
